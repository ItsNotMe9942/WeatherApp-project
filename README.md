# Weather App Project

An early Python command-line weather application built as a learning project.

This version uses a small set of hard-coded weather data and a terminal interface. It was created to practise Python fundamentals including functions, dictionaries, loops, user input, validation and exception handling.

## Project Evolution

This repository represents an early stage of the weather-app idea. I later developed the concept further in my `tkinter-Weather-App` project, replacing the command-line interface with a graphical UI and using live weather data from the OpenWeatherMap API.

The repositories are kept separately to preserve that progression rather than presenting the earlier version as a finished application.
