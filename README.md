# Weather App Project

An early Python command-line weather application built as a learning project.

This version uses a small set of hard-coded weather data and a terminal interface. It was created to practise Python fundamentals including functions, dictionaries, loops, user input, validation and exception handling.

## Project Context

This repository is one of several separate weather-app learning exercises I worked on while exploring different ways of building software.

I later revisited the same basic idea in `tkinter-Weather-App`, using a graphical interface and live weather data from the OpenWeatherMap API. The two repositories are separate learning projects rather than iterations of one continuously developed codebase.

They are kept public to preserve that learning progression rather than presenting the earlier version as a finished application.
